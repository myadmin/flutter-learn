扎实的 Dart 核心功底 (Day 1)

从基础变量、空安全、数据结构，到面向对象、类继承、接口、Mixin 混入，再到异步 Future 与事件循环，全方位打通 Dart 语言脉络。

🧩

体系化 Flutter 核心组件 (Day 2)

深入解析 StatelessWidget 与 StatefulWidget 生命周期、各种排版布局、滚动视图、组件通信、Dio 网络请求封装与高级路由系统。

🛍️

实战一：仿电商商城项目 (GetX)

包含底部导航栏、轮播图、分类推荐、上拉加载、下拉刷新、用户登录验证、GetX 响应式状态管理、Token 本地持久化与通用弹窗封装。

📚

实战二：豆瓣电子书城 APP (Provider)

基于豆瓣阅读/读书真实生态，涵盖 HTML DOM 爬虫逆向提取、Provider MVVM 状态流转、微光骨架屏动效、明暗主题与懒加载导航。

📱

全平台多端部署与适配

不仅包含常规的 Web 与 Android 原生打包，还涵盖 Mac/iOS 运行调试以及华为鸿蒙 HarmonyOS 侧 Flutter 跨端实战。

💻

内置交互式代码与真机模拟器

网页内嵌手机模拟器与 Dart 交互式控制台，支持代码实时效果预览、状态变更查看与核心逻辑验证。
