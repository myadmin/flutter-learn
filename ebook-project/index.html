📺 B站视频课程：【Flutter】电子书城APP - 你的豆瓣阅读也可能是电子书城 (BV1dpg5eSETx)
🔗 官方开源源码：SX-Code/ebook (GitHub)
💡 核心定位：从传统的 RESTful JSON 接口跨越到 HTML DOM 逆向爬虫、Provider 响应式 MVVM 架构、微光流动骨架屏 (Shimmer) 与明暗双主题自适应 的进阶企业级实战。

1. 为什么选择“电子书城”作为进阶实战？ ​

在完成了“实战一：仿网易严选电商商城”后，我们已经掌握了常规移动端 App 的标准工业流（GetX、RESTful API 契约、Token 鉴权、瀑布流与分页）。然而，在真实企业级跨平台开发中，开发者往往还会遇到以下进阶场景与核心痛点：

  1. 没有标准的 RESTful JSON 接口怎么办？ 真实业务或个人作品常常需要聚合第三方开放数据（如豆瓣读书排行榜、书籍详情、用户书评、电子书试读）。此时必须利用网络请求结合 HTML DOM 树解析与 CSS 选择器抽取，构建高可用、防反爬、容错降级的爬虫服务。
  2. 状态管理选型权衡：GetX vs 官方推荐 Provider 虽然 GetX 开发迅速，但在大型工程或团队协作中，Google 官方主推的 Provider（基于 InheritedWidget 深度优化）依然是面试和架构考核的核心标准。
  3. 首屏渲染与转圈加载体验落差 传统居中菊花加载（CircularProgressIndicator）会给用户强烈的等待感和割裂感。现代化顶级应用（如知乎、豆瓣、小红书）均全面拥抱 微光流动骨架屏 (Shimmer Skeleton)，在数据尚未到达前呈现高度贴合页面结构的微光占位。
  4. 多设备屏幕自适应与明暗夜间模式 (Dark Mode) 不同机型的物理分辨率、DPI、文字缩放倍率各不相同；同时阅读类应用对夜间模式（深色护眼背景、降低文本对比度）有着刚性诉求。

本项目正是针对以上所有痛点精心打磨的进阶案例！

3. 项目核心功能全景 ​

【Flutter】电子书城 APP 核心功能图景
│
├── 🏠 首页 (HomePage)
│   ├── 顶部防抖搜索栏与明暗双主题动态切换
│   ├── 豆瓣编辑精选重磅推荐横幅 (Banner 轮播)
│   ├── 今日精选书籍卡片流与星级评分展示
│   └── 页面加载时微光流动骨架屏 (Shimmer Skeletons)
│
├── 📚 豆瓣读书商城 (DoubanStorePage)
│   ├── 豆瓣读书 Top 250 榜单数据实时爬取解析
│   ├── 热门新书速递与不同分类标签联动筛选
│   └── 触底自动分页增量流式抓取
│
├── 🏷️ 电子书城分类 (EBookStorePage)
│   ├── 豆瓣阅读热门分类金刚区 (科幻、文学、悬疑、经济等)
│   └── 分类图书网格瀑布流展示与单价信息
│
├── 📖 图书详情全景 (BookDetailPage)
│   ├── 渐变透明沉浸式 AppBar 与封面背景高斯模糊 (BlurryContainer)
│   ├── 星级评分条 (FlutterRatingBar) 与精准评分比率
│   ├── 长文本内容简介自适应展开/收起 (ReadMoreText)
│   ├── 作者生平卡片与图书章节目录手风琴
│   └── 真实读者精彩书评瀑布流展示
│
└── 👤 个人书架与阅读器 (MyBookPage)
    ├── 本地已加书架电子书管理
    └── 轻量级沉浸式阅读器与翻页交互

5. 两大实战项目技术架构深度对比 ​

为了让大家建立全面的 Flutter 架构视野，我们将本教程中的两大实战项目进行横向对比：

评估维度实战一：仿网易严选电商商城实战二：豆瓣阅读电子书城 APP
主要定位大厂商用 B2C 电商平台标准交付体系现代高颜值内容消费与资讯聚合类应用
状态管理方案GetX（响应式 .obs + Controller + Obx）Provider（ChangeNotifier + ViewModel + Consumer）
路由导航机制GetX 命名路由 / 动态路由管理Flutter 原生 Navigator 路由封装与参数透传
数据源契约标准 RESTful JSON 格式接口 + Swagger 契约HTML 网页 DOM 逆向爬虫 (package:html 解析)
底部导航架构原生 BottomNavigationBar + IndexedStackSalomonBottomBar + LazyLoadIndexedStack 懒加载

6. 进阶学习路线图 ​

学习本系列文档建议按照以下顺序循序渐进：

  1. 工程规范、屏幕适配与明暗主题系统：搭建规范目录，接入 ScreenUtil 与 ThemeProvider；
  2. 高颜值流光底部导航与懒加载堆栈：实现 Salomon 流光气泡栏与懒加载导航栈优化；
  3. Dio 网络封装与 HTML DOM 爬虫逆向工程：掌握防反爬 Header 伪装与豆瓣 DOM 树解析实战；
  4. 领域模型设计与 Provider MVVM 状态流转：编写清晰健壮的 Model 与 ViewModel 分层；
  5. 微光流动骨架屏体系与高质感组件库：设计优雅的 Shimmer 骨架屏组件对；
  6. 图书详情页全景与阅读器沉浸式体验：打造高斯模糊、星级评分与阅读器翻页综合大招！
